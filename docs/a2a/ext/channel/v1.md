# Channel extension v1

**URI:** `https://madarauchiha-314.github.io/tiny-harness/a2a/ext/channel/v1`
**Media type:** `application/vnd.tiny-harness.channel+json`

A channel is a set of participants the harness manages. Over A2A, a send becomes a
message event on the task carrying a data part of this media type, persisted before it
is delivered; a participant sends by calling `SendMessage` on the task with the same
part. Membership is the boundary: a message from a non-member is refused with the same
error whether or not the channel exists.

A channel message has a `kind` of `message`, `help_request` or `help_reply`; a help
request is answered by a reply from the participant it was addressed to, which resumes
the waiting task.
