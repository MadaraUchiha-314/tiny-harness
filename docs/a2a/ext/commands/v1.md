# Commands extension v1

**URI:** `https://madarauchiha-314.github.io/tiny-harness/a2a/ext/commands/v1`

A message whose only part is the text `/<name> <arguments>`, where `<name>` is a
registered command, runs that command on the harness instead of reaching the model. The
reply arrives as the message of a re-emitted status update whose metadata is
`{"command": "<name>"}`, plus `"task_ref": "<id>"` when the command created a sub-task.
The task's state does not change. A `/<name>` that is not registered is an ordinary
message.

The agent card lists the registered commands in this extension's `params`, so a client
can offer them as completions without another request:

```json
{
  "uri": "https://madarauchiha-314.github.io/tiny-harness/a2a/ext/commands/v1",
  "required": false,
  "params": {
    "commands": [
      { "name": "model", "description": "Show or choose this task's model", "argument_hint": "[<model>]" }
    ]
  }
}
```

## Surface commands

Most commands run on the agent. A **surface command** runs in the client, because it
needs something that only the client has, for example a file on the user's computer.
Its entry on the card has the optional key `runsOn` with the value `surface`. An entry
without `runsOn` is a command that runs on the agent.

```json
{ "name": "attach", "description": "Attach a local image or audio file to your next message", "argument_hint": "<path>", "runsOn": "surface" }
```

- A client that implements a surface command runs it locally and sends nothing to the
  agent.
- A client that does not implement it sends the text like any command. The agent then
  replies that the command runs in the client, for example
  `/attach runs in your client; this client cannot attach files`.
- A client implements only the surface commands that the card lists. It does not add
  commands of its own.

The built-in surface command is `/attach <path>`. The card lists it only when the agent
accepts media (the [media extension](../media/v1.md)).
