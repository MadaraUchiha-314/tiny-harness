# Commands extension v1

**URI:** `https://madarauchiha-314.github.io/tiny-harness/a2a/ext/commands/v1`

A message whose only part is the text `/<name> <arguments>`, where `<name>` is a
registered command, runs that command on the harness instead of reaching the model. The
reply arrives as the message of a re-emitted status update whose metadata is
`{"command": "<name>"}`, plus `"task_ref": "<id>"` when the command created a sub-task,
and `"close_client": "true"` when the command asks the sender's client to close (the
built-in `/exit`). A client closes only for a reply on the stream of its own message, not
for one it sees on a subscription. The task's state does not change. A `/<name>` that is not registered is an ordinary
message.

The agent card lists the registered commands in this extension's `params`, so a client
can offer them as completions without another request:

```json
{
  "uri": "https://madarauchiha-314.github.io/tiny-harness/a2a/ext/commands/v1",
  "required": false,
  "params": {
    "commands": [
      { "name": "model", "description": "Show or choose this task's model", "argument_hint": "[<model>]" }
    ]
  }
}
```
