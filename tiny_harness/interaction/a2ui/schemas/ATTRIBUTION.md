# A2UI schemas

The JSON files in this directory are the A2UI specification's version 0.9 schemas and
basic catalog, copied unchanged from <https://github.com/a2ui-project/a2ui>
(`specification/v0_9/json/*.json` and `specification/v0_9/catalogs/basic/catalog.json`),
licensed under the Apache License 2.0 (see `LICENSE` beside them). tiny-harness
validates every A2UI payload it emits or accepts against them (requirement 20.5).
